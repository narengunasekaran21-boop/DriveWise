# 🚗 DriveWise – Smart Car Recommendation System

DriveWise is a modern web application that helps users find the perfect car based on their budget, lifestyle, fuel preference, family size, transmission, and personal priorities. Instead of spending hours comparing cars manually, DriveWise provides personalized recommendations in just a few clicks.

---

## 🌟 Features

* 🚘 Smart Car Recommendation Engine
* 🔍 Browse 100+ Indian Cars
* ⚖️ Compare Cars Side-by-Side
* 💰 EMI Calculator
* ❤️ Save Favourite Cars
* 📱 Fully Responsive Design
* 🎨 Modern & Clean User Interface
* ⚡ Fast and Lightweight (Vanilla JavaScript)

## 💡 How It Works

1. Enter your budget.
2. Choose fuel type.
3. Select transmission.
4. Specify family size.
5. Set your priorities.
6. Receive personalized car recommendations.
7. Compare shortlisted cars and calculate EMI before making a decision.
